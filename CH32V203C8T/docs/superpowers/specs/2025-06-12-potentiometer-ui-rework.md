# 电位器 UI 重构设计

> **日期:** 2025-06-12
> **关联文件:** `hid_adc_monitor.py`

## 目标

将当前列表式 ADC 显示（`QTableWidget`）替换为 8 个水平排列的电位器部件，每个部件包含可拖动的 Slider、ADC 指示器和 PWM 数字显示。保留底部调试控制台。

## 每个电位器部件

### 组成

| 元素 | 类型 | 说明 |
|------|------|------|
| **Slider** | 可拖动 `QSlider`，垂直，0~4095 | 设置目标位置，滑块位置对应 `target_adc` |
| **ADC 指示器** | 自定义 `QPainter` 绘制：竖线 + 横线 | 仅显示当前 `current_adc`，不可交互 |
| **PWM 数字** | `QLabel` | 显示 `duty` 原始值 |
| **CH 标签** | `QLabel` | 显示 "CH1" ~ "CH8" |

### Slider 交互

- 拖动 Slider 时更新本地目标值显示
- 本次**不发送 HID1 OUT 命令**到固件（后续扩展）
- 范围 0~4095，对齐 ADC 分辨率

### ADC 指示器绘制

每个指示器是一根垂直线（表示 0~4095 范围），在对应 ADC 值的垂直位置画一条水平短线作为标记。

## 自适应

- 8 个部件放在 `QHBoxLayout` 中，每个宽度 = `可用宽度 / 8`
- 高度由 `QSplitter` 上半部分决定
- 窗口缩小时 8 列同步缩小

## 代码变更

### 移除

- `QTableWidget` 及其相关代码（`_table`, `COL_*` 常量, `ProgressBarDelegate`, `_bar_delegate` 等）
- `QHeaderView` 导入
- `QStyledItemDelegate` 导入

### 新增

- `class PotWidget(QWidget)` — 自定义电位器控件，含 `QSlider` + ADC 指示器绘制 + `QLabel`
- 8 个 `PotWidget` 实例水平排列
- `_update_pots(StatusReport)` 替换 `_on_data` 中的表格更新逻辑

### 保留

- `HidWorker` / `HidDebugWorker` / `StatusReport`
- 调试控制台（`QPlainTextEdit`）
- 状态栏 / FPS / 连接指示
