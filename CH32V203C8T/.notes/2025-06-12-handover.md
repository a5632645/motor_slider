# 交接文档 — 2025-06-12

## 今日完成工作

### USB 子系统重构 (CH32V203C8T, USBFS)
- 从 USBHS(旧) 迁移到 USBFS(当前): 所有寄存器 `USBHSD→USBFSD`, `USBHS_xxx→USBFS_xxx`
- USB 中断处理重构: USBHS 有独立 `UIF_SETUP_ACT`，USBFS 合入 `UIF_TRANSFER` 的 `UIS_TOKEN_SETUP`
- 删除 `ENDP_CONFIG`/`ENDP_TYPE`/`HOST_CTRL`(USBFS 无)
- 修复 STATUS 阶段后错误发送 ZLP 的 bug (`EpOutComplete`)
- 删除 UAC2/CDC 复合设备描述符，改为纯 HID 描述符
- 枚举从 `kUsbEndpoint_1` 改为 `kUsbEndpoint_HidIn`(语意化)
- `_HidInHandler` 提取为独立函数，PID 翻转在 `UsbImpl_EpInComplete` 中完成
- USB RCC 初始化从硬编码改为运行时检测 SYSCLK 频率

### Tick 子系统
- SysTick 配置修复: bit2 不是时钟源位，bit5 才是；需 `CNT_CLR(1<<4)` + 清 `SR`
- 提取 `tick.c/h`，`tick_` 为 static 全局，通过 `Tick_Init/Get/Increment` 访问

### HID 双接口
- HID0: printf(EP1 IN, 现有)
- HID1: 电机控制(EP2 IN+OUT, 新增)
- tpusb 模板生成复合 HID 描述符

### 电机控制 (新建)
- `motor.c/h` + `pid.c/h`
- PWM: TIM1~4, 96kHz, ARR=999
- ADC: 8ch scan + DMA1 CH1, 软件触发
- PID: 位置式 PID + 积分限幅
- 控制流水线: SysTick→ADC(sw trigger)→DMA→main loop→PID→PWM

### 已修复 Bug
1. USB STATUS 阶段后发送多余 ZLP → 删掉
2. SysTick 配置位错误(bit2→bit5) → 修正

## 用户提问模式

1. **先确认再执行**: 每次修改前先问"先确认一下需求理解和方案，如果有不合理或遗漏的地方，顺便指出来"
2. **官方例程对比**: 遇到 bug 先贴官方例程，让子代理对比审查，输出差异优先级(P0/P1/...)
3. **分段验证**: 每次修改后编译验证，不接受跳过编译
4. **明确拒绝废话**: 汇报保持高信息密度

## 任务完成流程

```
用户需求 → 读取相关代码 → 输出方案确认(await) → 
执行 → 编译验证 → 汇报结果
```

## Bug 寻找流程

```
Bug 报告 → 对比官方 EXAM 例程 → 子代理审查 →
输出差异列表(P0/P1/...) → 按优先级修复 → 编译验证
```

## 编码规范(最终版)

- 全局变量: `_` 结尾
- static 函数: `_` 开头
- 公开函数: `模块_动作`
- 枚举: `k` + 模块名 + PascalCase
- 禁止 typedef struct/enum
- 禁止 extern 全局变量
- Doxygen 注释
- 中断: `__attribute__((interrupt("WCH-Interrupt-fast")))`
- USB 枚举: `kUsb` 前缀
