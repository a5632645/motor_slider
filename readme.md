# motor_slider
8个电动推子与MIDI CC的联动**原型机**测试

> [!NOTE]
> 本存储库含有大量AI生成内容，如果你不喜欢AI，请立刻返回

## 功能
8个电动推子，根据DAW MIDI CC移动位置，也能将电位器位置通过MIDI CC上传到DAW，两个操作不允许发生在同一时间，也不会进行抢占操作    
有7个推子含有原生PWM控制，另一个使用TIM+DMA写GPIO的形式模拟PWM  
电机控制器在小范围移动会产生可听的来回移动噪声  
MIDI CC目前固定为CC0~CC7  
> [!NOTE]
> 接下来的面板使用M3螺丝时选择平头的，否则midi cc的范围会变成 2~124
